Turn on the keyboard

  • Open Settings → General → Keyboard → Keyboards
  • Tap Add New Keyboard… and choose WideKeys
  • In any app, hold the 🌐 key and pick WideKeys

To make WideKeys the keyboard that opens, tap Edit in that list and drag WideKeys to the top. Password boxes always use the phone's own keyboard; that's a system rule for every keyboard app.

Do I need "Allow Full Access"?

No. WideKeys works without it. Turning it on adds haptics, key sounds, the clipboard, and lets the keyboard use the themes and settings you choose in the WideKeys app. WideKeys has no internet code, so nothing you type is ever sent anywhere.

Add or remove a language

Open the WideKeys app → Settings → Languages → Add language. Switch languages by swiping across the space bar, with a language key beside 123, or both: choose in Settings → Languages → Switch language with. WideKeys types English, Arabic, Polish, Spanish, and English + Polski together.

Change the look

Open the WideKeys app → Themes. Pick a style, its colours, key size and tap effect, then tap Save.

User guide

The WideKeys app has a full, searchable guide: open the app and tap User guide.

Report a problem

In the WideKeys app, go to Settings → Diagnostics and tap Email report. You can see the whole report before sending it; it never contains anything you typed.

Contact

Email widekeys.support@gmail.com. We usually reply within a few days.
